# Experiment 2.1.1 — RESTful API
Implements CRUD REST APIs using Controller → Service → Repository architecture.

**Run:** `mvn spring-boot:run`
**Port:** 8081
**Endpoints:** GET/POST/PUT/DELETE `/api/posts`

Validation uses `@Valid`, `@NotBlank`, and `@Size`. CORS is enabled for a frontend running on port 5500.
